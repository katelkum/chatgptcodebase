# Stato — Deep Research Agent v2.0
**Realizzato:** protocollo operativo multi-motore; uso indipendente dei tool nativi anche con plugin funzionanti; fallback tra plugin e nativi; ricerca discovery-first, multilingue, esclusioni, contraddizioni, knowledge graph, dashboard, archiviazione opzionale; template per report e registri.

**Non realizzato:** software orchestratore eseguibile, database del knowledge graph, dashboard applicativa, worker Railway, schedulazione, integrazione automatica API. Queste funzionalità richiedono un progetto di sviluppo separato, scelta dell'ambiente e autorizzazione prima di eventuali costi/deploy.

**Verifiche disponibili da test precedenti:** Tavily, Parallel Search, Firecrawl, GitHub, Railway e alcuni altri connettori hanno risposto a test limitati. La loro disponibilità futura non è garantita; ogni nuova sessione deve verificarla.
